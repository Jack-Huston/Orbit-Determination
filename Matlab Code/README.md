# MATLAB Projects

This repository contains MATLAB implementations of control systems and state estimation algorithms.

## Getting Started

### Available Projects

- **Extended Kalman Filter** - Implementation of an Extended Kalman Filter for state estimation
- **Linear Controller** - Linear control system implementation

### How to Run

1. **Download the project folder**
   - Download either the entire `Extended Kalman Filter` folder or the entire `Linear Controller` folder
   - Keep all files in their original locations within the folder

2. **Open MATLAB**
   - Navigate to the downloaded project folder in MATLAB

3. **Run the project**
   - Execute the `Main.m` script
   - No configuration or file path changes are needed

### Requirements

- MATLAB (version compatible with the code in this repository)

### Notes

Each project is self-contained within its respective folder. Simply download the folder you're interested in and run `Main.m` to see the results.
